# 코난킴 (Konan Kim) 플레이리스트

10곡을 두 바퀴 이어 붙인 연속듣기 영상입니다. 길이는 1시간 34분, 화면은 1920×1080입니다.

## 영상 받는 법

GitHub에는 파일 하나에 100MB까지만 올라가서, 영상을 16조각(`.part00` ~ `.part15`)으로 나눴습니다.

1. 저장소 화면의 초록색 **Code** 버튼에서 **Download ZIP**을 눌러 전체를 받습니다.
2. 압축을 풉니다.
3. 아래 방법으로 조각을 합칩니다.
   - **Windows:** `join_windows.bat`를 더블클릭합니다.
   - **Mac:** 터미널에서 `sh join_mac.sh`를 실행합니다.
4. 같은 폴더에 `KonanKim_Playlist_1h34m.mp4`가 생깁니다.

합친 파일이 원본과 같은지 확인하려면 `KonanKim_Playlist_1h34m.sha256`에 적힌 값과 비교하면 됩니다.
